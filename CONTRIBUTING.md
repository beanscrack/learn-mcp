# Contributing to learn-mcp

Thank you for your interest in contributing to `learn-mcp`! This project aims to provide UWaterloo students with a powerful MCP server for their academic and co-op needs.

## Getting Started

1.  **Fork the repository** on GitHub.
2.  **Clone your fork** locally:
    ```bash
    git clone https://github.com/YOUR_USERNAME/learn-mcp.git
    cd learn-mcp
    ```
3.  **Install dependencies**:
    ```bash
    npm install
    ```
4.  **Create a feature branch**:
    ```bash
    git checkout -b feature/my-new-feature
    ```

## Development

-   **Build**: `npm run build`
-   **Test**: `npm test`
-   **Lint/Typecheck**: `npm run build` (tsc will report errors)
-   **Diagnostics**: `npm run doctor`

## Pull Request Process

1.  Ensure your code follows the existing style (TypeScript, ESM).
2.  Add unit tests for any new utility logic in `src/utils/`.
3.  Update the README if you add new tools or change configuration.
4.  Submit a PR to the `main` branch.

## Code of Conduct

Please be respectful and helpful to other contributors. This is a student-led project for the UWaterloo community.
